# Zaheen Kintwear – Frontend (React JS)

This is the **frontend** part of the Zaheen Kintwear Full-Stack Assessment Project for **Goinnovior Limited**.  
It is built with **React JS** and fully integrated with **Firebase Authentication** and the **backend API**.

---

## 🚀 Live Demo
🔗 Frontend: https://zaheenkintwear-client.vercel.app

---

## 📂 Tech Stack
- React JS
- Tailwind CSS
- React Router DOM
- Firebase Authentication (Email + Google)
- Axios (API requests)
- Context API (Cart & Auth state)

---

## 📱 Responsiveness
The frontend is fully responsive across **4 devices**:
- Mobile
- Tablet
- Laptop
- Desktop  

All UI elements follow the Figma design shared by HR.

---

## 🔐 Authentication Features
- Login / Registration (Email & Password)
- Google Social Login
- User profile display in navbar
- Logout functionality
- Real-time navbar account update

---

## 🛒 Add to Cart Functionality
- Add products to cart dynamically
- Cart count updates in navbar instantly
- If the same product is added again, quantity increases
- Cart persists across reloads (fetch from backend)
- Product data comes from **MongoDB CMS** dynamically

---

## 📡 API Integration
- Fetch products from backend: `GET /products`
- Add product to cart: `POST /cart`
- Get cart items: `GET /cart`

All requests are **real dynamic requests**, no static values.
